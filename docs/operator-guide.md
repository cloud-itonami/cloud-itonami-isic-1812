# Operator Guide

## First Deployment
1. Register operator, pre-press/bindery lines, job-specification and
   equipment-safety scope, staff and robots.
2. Import existing job and quality-record history.
3. Run read-only job-specification-scope and plate-making/cutting/
   folding/binding robot mission dry-runs.
4. Configure safety-class allowed sets and human sign-off paths.
5. Publish a dry-run release record and audit export.

## Minimum Production Controls
- job-specification and equipment-safety-scope validation before any
  cutting/binding dispatch
- governor gate on every robot action before dispatch
- human sign-off for :high/:safety-critical actions (a job release
  without a completed quality inspection, a cutting/binding job
  outside verified equipment-safety scope)
- evidence-backed release records
- audit export for every dispatch, sign-off and release
- backup manual print-support review

## Certification
Certified operators must prove robot-safety integrity, job-
specification/equipment-safety discipline, evidence-backed release
records and human review for release-affecting actions.
